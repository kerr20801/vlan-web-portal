【VMware VLAN 批次自動部署與虛擬機開通控制台】使用說明

✨ 本工具解決的核心維運痛點：
1. 【網路部署太繁瑣】：新上架 ESXi 伺服器時，若有 60 個 VLAN，傳統做法需要在網頁後台手動點擊 60 次「新增 Port Group」並手動輸入 60 次 VLAN ID，極度耗時且容易打錯。本工具可直接從 Excel 貼上清單，一鍵自動完成整批建立與比對！
2. 【網卡切換驗證難】：更換 VM 網卡 VLAN 後，常需切換不同工具測試連通性。本工具內建 Ping / SSH / RDP / 自訂 TCP / UDP 多協定驗證。
3. 【新人環境開通慢且無 IP】：克隆母機時常因環境無 DHCP 導致 VM 開機失聯。本工具提供「一鍵自動尋找空閒 IP」、「即時 IP 衝突檢查」、「RFC 1123 電腦名稱合規校驗」與「VMware Tools 即時連線狀態追蹤」，實現真正一鍵部署。

============================================================
🚀 快速上手步驟：
============================================================
1. 雙擊執行【啟動服務.bat】。
2. 系統會自動在預設瀏覽器開啟控制台（網址：http://localhost:8899/）。
3. 點擊右上角【⚙️ 尚未連線】輸入您的 vCenter (如 vc.domain.com) 或 ESXi 主機帳密，點擊「連線並載入設定」。

------------------------------------------------------------
📑 分頁 1：VLAN 批次建立與主機網路同步
------------------------------------------------------------
- 選擇【目標 ESXi 主機】：
  * 系統會自動讀取該主機上的現有網路，並與下方清單進行「即時現況比對 (Live Diff)」！
  * 預覽表格會清楚標示出哪些已存在主機中（標記綠色略過）、哪些是待建立項目（標記藍色）。
- 在文字方塊中貼上您的 VLAN 清單（格式：vSwitch名稱, PortGroup名稱, VLAN_ID）：
  * 支援直接從 Excel 複製貼上（支援逗號、Tab、空格）。
  * 亦可點擊【🔄 從既有主機複製】直接將運行中主機的網路規格提取出來。
  * 具備【💾 本機草稿自動保存】功能：中途離開、按 F5 或電腦斷線重啟，草稿依然原樣保留！
- 點擊執行部署：
  * 可點擊【⚡ 立即執行批次部署 (全部項目)】進行完整推送。
  * 或點擊【🎯 僅部署未完成項目】自動過濾已存在的項目，進行精準斷線續接！
- 完成後可點擊【📥 匯出部署結果報表 (.csv)】將明細存檔留存或匯報。

------------------------------------------------------------
🔌 分頁 2：VM 網卡切換與多協定連通性驗證
------------------------------------------------------------
- 選擇目標虛擬機與欲綁定的 vSwitch / VLAN (PortGroup)。
- 選取連通性驗證協定：
  * Ping (ICMP)
  * SSH (Port 22)
  * RDP (Port 3389)
  * 自訂 TCP Port
  * UDP 連通性檢驗 / 主動探測 (Active Probing)
- 點擊【切換並驗證網路連通性】，系統會自動換網卡並執行 3 次重試緩衝驗證，避免誤報。

------------------------------------------------------------
👥 分頁 3：VM 實驗室一鍵克隆與開通
------------------------------------------------------------
- 選取母體 VM 範本與目標 ESXi 主機 / Datastore。
- 設定新 VM 名稱：系統會自動根據 RFC 1123 規範過濾非法底線與空格，產生合規電腦名稱（Windows 自動截斷 15 字元、Linux 63 字元）。
- 智慧 IP 設定（預設為靜態 IP）：
  * 可點擊【⚡ 自動尋找空閒 IP】：背景高速掃描網段，自動為您填入可用 IP、閘道、遮罩與 DNS。
  * 或手動輸入 IP 後點擊【🔍 檢查 IP 衝突】：即時 Ping 檢驗是否已有設備佔用。
  * 輸入 IP 時系統會自動推算預設閘道 (.1) 與子網路遮罩。
- 點擊【🚀 立即執行克隆與自動配網】：
  * 克隆後若勾選自動開機，系統會自動套用全新 SID (Windows) 或 cloud-init (Linux)。
  * 部署完成後，下方監控卡會向 VMware Tools 即時追蹤實體 IP，在線後提供【📋 複製 SSH/RDP 指令】一鍵連線！

============================================================
附註強大功能：
============================================================
1. 【中斷連線 (登出)】：點擊右上角「🔌 斷開連線」可隨時釋放連線 Session，安全切換其他主機。
2. 【📥 匯出清單 CSV】：隨時將清單備份成 Excel 可直接開啟的 CSV 檔案（內建 UTF-8 BOM，保證中文不亂碼）。
3. 【隨身碟即插即用】：本工具支援將 PowerCLI 模組直接置於 Modules 資料夾，不需連外網，適合各類機房跳板機。
