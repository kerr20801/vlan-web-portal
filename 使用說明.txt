【VMware VLAN 批次自動部署與切換控制台】使用說明

✨ 本工具解決的核心痛點：
當機房上架新的一台 ESXi 伺服器時，若有 vSwitch0 (20個 VLAN) 與 vSwitch1 (40個 VLAN)，傳統做法需要在網頁後台手動點擊 60 次「新增 Port Group」並手動輸入 60 次 VLAN ID，極度耗時且容易打錯。
本工具讓您可以直接從 Excel 貼上 60 筆清單，一鍵自動完成整批建立！

🚀 快速上手步驟：
1. 雙擊執行【啟動服務.bat】。
2. 系統會自動在預設瀏覽器開啟控制台（網址：http://localhost:8899/）。
3. 點擊右上角【⚙️ 尚未連線】輸入您的 vCenter (如 vc.domain.com) 或 ESXi 主機帳密，點擊「連線並載入設定」。
4. 選擇【目標 ESXi 主機】：
   - 系統會自動讀取該主機上的現有網路，並與下方清單進行「即時現況比對 (Live Diff)」！
   - 預覽表格會清楚標示出哪些已存在主機中（標記綠色略過）、哪些是待建立項目（標記藍色）。
5. 在文字方塊中貼上您的 VLAN 清單（格式：vSwitch名稱, PortGroup名稱, VLAN_ID）：
   - 支援直接從 Excel 複製貼上（支援逗號、Tab、空格）。
   - 亦可點擊【🔄 從既有主機複製】直接將運行中主機的網路規格提取出來。
   - 具備【💾 本機草稿自動保存】功能：中途離開、按 F5 或電腦斷線重啟，草稿依然原樣保留！
6. 點擊執行部署：
   - 可點擊【⚡ 立即執行批次部署 (全部項目)】進行完整推送。
   - 或點擊【🎯 僅部署未完成項目】自動過濾已存在的項目，進行精準斷線續接！
7. 完成後可點擊【📥 匯出部署結果報表 (.csv)】將明細存檔留存或匯報。

附註強大功能：
1. 【中斷連線 (登出)】：點擊右上角「🔌 斷開連線」可隨時釋放連線 Session，安全切換其他主機。
2. 【📥 匯出清單 CSV】：隨時將清單備份成 Excel 可直接開啟的 CSV 檔案（內建 UTF-8 BOM，保證中文不亂碼）。
3. 【🔌 VM 網卡切換】：支援自選連通性驗證協定（Ping / RDP / SSH / 自訂 Port），內建自動重試緩衝，不再因 Windows 未開 SSH 而誤報。
4. 【👥 虛擬機自動克隆與配網】：支援範本 VM 一鍵克隆，並自動套用全新 Computer Name、靜態 IP 與 SID。
5. 【隨身碟即插即用】：本工具內建 PowerCLI 核心模組（位於 Modules 資料夾），不需連外網，適合各類機房跳板機。
